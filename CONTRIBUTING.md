# Contributing to Physics Anatomy

Thank you for wanting to help. Physics Anatomy is a virtual physics lab for SHS (WASSCE) to
university students.

## What you can do now

- **Report a problem or suggest an experiment**: open an issue.
- **Review the physics**: if you teach physics, every model and experiment is checked by a physics
  reviewer before it ships (`.github/CODEOWNERS`). Say so in an issue and we'll be in touch.

## Code

The repository is public, but it has no licence yet: the licence is to be agreed with the
University of Education, Winneba. Until it is, we can't accept code from outside the team. Code
contributions open once the licence is agreed.

## Being credited

Contributors are listed on the site's `/contribute` page from `CONTRIBUTORS.yml`, once they agree
to be, in their own words.

For how the project is run, read `AGENTS.md`, `design/README.md` and the decision records in
`docs/adr/`.
