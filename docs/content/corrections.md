# Corrections to the source material

Every error found in the source book is recorded here with the corrected working, so teachers
can see what changed and why (master plan, "Corrections log"). Each correction is also a test in
the experiment that uses it.

| Where                       | The book says                                      | Correct                 | Working                                                                                    |
| --------------------------- | -------------------------------------------------- | ----------------------- | ------------------------------------------------------------------------------------------ |
| Helical spring, second part | S = 12.5 N/m                                       | 12.6 N/m (3 s.f.)       | S = 9.8 × 0.050 ⁄ 0.039 = 0.490 ⁄ 0.039 = 12.56 N/m                                        |
| Helical spring, part b(i)   | "a force of 1.2 N causes a total stretch of 20 cm" | "total length of 20 cm" | Solved as a final length; read as an extension, the two data points contradict Hooke's law |
