# 0029. No dummy content on the site

- Status: accepted
- Date: 2026-11-06
- Decision log entry: D29 in `docs/planning/00-decisions.md`

## Decision

No dummy content on the site.

## Details and consequences

Every number on the public site is either computed from the physics or a stated fact. No fake counters, version numbers, partner links or unplanned experiments. Dashboards show example data only with a visible "Example data" label, using the 1,000-student cost scenario.
