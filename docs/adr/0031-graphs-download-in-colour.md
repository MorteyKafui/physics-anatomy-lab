# 0031. Graphs download in colour

- Status: accepted
- Date: 2026-11-06
- Decision log entry: D31 in `docs/planning/00-decisions.md`

## Decision

Graphs download in colour.

## Details and consequences

Colour or black-and-white choice in the export dialog (PNG, SVG, PDF). Colour uses the topic hue for points, #F0482A for the fit line, a distinct slope-triangle colour, a hue per series plus marker shapes, green graph-paper ruling; checked for contrast and colour-blind safety. Teachers can set the class default. Master plan updated.
